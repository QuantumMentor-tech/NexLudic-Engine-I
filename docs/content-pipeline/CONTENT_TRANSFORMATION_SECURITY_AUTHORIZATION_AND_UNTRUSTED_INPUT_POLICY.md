# Content Transformation Security, Authorization & Untrusted-Input Policy

---

## 1. Scope & Transformation Threat Model

Asset transcoding processes complex binary files (meshes, textures, sound banks) that have historically served as attack vectors for buffer overflows, memory corruption, and out-of-bounds execution. This policy defines mandatory sandboxing, privilege minimization, input sanitization, and licensing propagation rules.

---

## 2. Isolated Sandboxed Execution Boundary

To satisfy `P7-C02` and `INV-TRF-01`:
1. **Out-of-Process Execution:** All transcode adapters must run as unprivileged child worker processes isolated from the main NexLudic Engine process.
2. **Standard IPC Communication:** Workers communicate strictly via canonical protobuf messages over anonymous pipes or standard input/output.
3. **No Direct OS or Live Game Access:** Workers are restricted to reading the staged input payload and writing to `.staging/transcode_<run_id>/`.
4. **Privilege Boundary:** Workers run strictly at Windows Medium Integrity Level. Administrative elevation is prohibited.

---

## 3. Untrusted Input Defenses & Fuzzing Mitigations

Converters must incorporate defensive parsing against adversarial or corrupt assets:
- **Integer Overflow Guards:** Validate accessor element counts multiplied by stride before memory allocation.
- **Buffer Bounds Checking:** Reject any chunk offset or length that exceeds total file boundaries.
- **Zero Script Execution During Conversion:** Converters must NEVER execute embedded Lua, Python, or bytecodes during conversion.
- **Resource Hard Limits:** Terminate any worker exceeding 4 GB RAM or 120 seconds of execution time (`ERR_RES_LIMIT_EXCEEDED`).

---

## 4. Licensing Propagation & Intellectual Property Safeguards

1. **License Inheritance:** Any derivative output artifact generated by transformation inherits the licensing restrictions (SPDX identifier, attribution requirements) of its source assets.
2. **Proprietary Asset Lockdown:** Transformed outputs derived from proprietary retail game content remain strictly classified as `LOCAL_USER_PRIVATE` and are blocked from export, sharing (Gate G7), or public redistribution (Gate G8).
