## 2. Synthetic Test Matrix: Scenarios A through AH

### Artifact Validation Scenarios (A–F)

#### Scenario A: Fully Eligible Transformed Artifact
- **Initial State:** NIF mesh `out-nif-blade-001` generated by Stage H; SHA-256 matches; Gate G5 granted; target build `1.6.1170.0`.
- **Execution:** Layer A through E validation passes.
- **Expected Outcome:** Marked `ELIGIBLE_FOR_PACKAGE_MEMBERSHIP`; admitted to candidate pool.

#### Scenario B: Missing Artifact Identity
- **Initial State:** Artifact descriptor lacks required canonical `artifact_id` and namespaced prefix.
- **Execution:** Layer A identifier check evaluates syntax.
- **Expected Outcome:** Rejection with `ERR_PVA_META_MISSING`; candidate blocked.

#### Scenario C: Content Changed After Validation
- **Initial State:** Artifact file bytes altered on disk after Stage I validation; digest diverges.
- **Execution:** Layer A cryptographic integrity check recomputes SHA-256.
- **Expected Outcome:** Rejection with `ERR_PVA_INTEG_MISMATCH`; prior validation invalidated.

#### Scenario D: Stale Transformation Output
- **Initial State:** Upstream source glTF modified; package definition still references earlier revision.
- **Execution:** Layer E freshness checker queries source revision head.
- **Expected Outcome:** Invalidation triggered; marked `ERR_PVA_EVID_STALE`; re-transcode required.

#### Scenario E: Unverified Use Authorization
- **Initial State:** Artifact is technically valid, but Gate G5 packaging authorization token is missing or expired.
- **Execution:** Layer D policy gate evaluates authorization.
- **Expected Outcome:** Admission blocked with `ERR_PVA_AUTH_REVOKED`.

#### Scenario F: Unsupported Target Format
- **Initial State:** Candidate artifact is an Unreal Engine 5 `.uasset` attempting inclusion in a Skyrim SE package.
- **Execution:** Layer C target compatibility validator matches format MIME against target engine profile.
- **Expected Outcome:** Rejection with `ERR_PVA_TARGET_MISMATCH`.

### Dependency Resolution Scenarios (G–P)

#### Scenario G: All Required Dependencies Resolve
- **Initial State:** Package requires `pkg.core.materials (^2.0.0)`; candidate `v2.1.4` available.
- **Execution:** SemVer resolution matches candidate.
- **Expected Outcome:** State `RESOLVED`; dependency edge bound in DAG.

#### Scenario H: Required Dependency is Missing
- **Initial State:** Package requires `pkg.audio.ambient-pack`, which is absent from registry.
- **Execution:** Dependency query returns zero candidates.
- **Expected Outcome:** Resolution pauses with `ERR_PVA_DEP_MISSING`; package marked `INCOMPLETE`.

#### Scenario I: Conflicting Version Constraints
- **Initial State:** Member 1 requires `pkg.mesh-base (>=1.0.0 <2.0.0)`; Member 2 requires `pkg.mesh-base (>=2.0.0)`.
- **Execution:** SemVer intersection yields empty set $\emptyset$.
- **Expected Outcome:** Assembly halted with `ERR_PVA_DEP_CONFLICT`.

#### Scenario J: Several Eligible Candidates
- **Initial State:** Candidates `v1.2.0`, `v1.2.1`, and `v1.3.0` all satisfy constraint `^1.2.0`.
- **Execution:** Deterministic tie-breaking selects highest compatible SemVer.
- **Expected Outcome:** `v1.3.0` deterministically selected.

#### Scenario K: Candidate is Newest but Incompatible
- **Initial State:** Candidate `v2.0.0` is newest release, but target build is legacy engine; only `v1.4.0` supports legacy build.
- **Execution:** Target compatibility filter prunes `v2.0.0` before version ranking.
- **Expected Outcome:** `v1.4.0` selected; recency does not override compatibility.

#### Scenario L: Optional Dependency Unavailable
- **Initial State:** Optional audio pack `pkg.sound.hd-cues` is missing.
- **Execution:** Optional dependency evaluation applies omission rule.
- **Expected Outcome:** `PackageExclusionRecord` logged; assembly proceeds with `VALID_WITH_WARNINGS`.

#### Scenario M: Required Dependency Cycle
- **Initial State:** Package $A$ requires $B$; Package $B$ requires $A$.
- **Execution:** `ALG-DAG-CYCLE` detects back-edge during DFS traversal.
- **Expected Outcome:** Immediate halt with `ERR_PVA_DAG_CYCLE`.

#### Scenario N: Self-Dependency
- **Initial State:** Artifact declares a dependency referencing its own `artifact_id`.
- **Execution:** Self-dependency check detects reflexive loop.
- **Expected Outcome:** Rejection with `ERR_PVA_DAG_CYCLE`.

#### Scenario O: Unverifiable External Dependency
- **Initial State:** Package references external binary mod from unverified third-party forum.
- **Execution:** Source trust evaluator checks external provider tier.
- **Expected Outcome:** Resolution blocked with `ERR_PVA_POLICY_BLOCK`.

#### Scenario P: Conditional Dependency Condition Unknown
- **Initial State:** Dependency required if `game_setting_enable_hd_textures == true`; setting cannot be resolved.
- **Execution:** Conditional evaluator encounters unknown environment state.
- **Expected Outcome:** Evaluated as required (fail-safe); candidate required before handoff.

- **Execution:** Destination collision detector compares normalized paths.

#### Scenario R: Duplicate Identity with Different Content
- **Initial State:** Two staged assets claim `out-nif-blade-001` with divergent hashes.

#### Scenario S: Mixed Target Releases

- **Execution:** Freshness check queries provider head.
- **Expected Outcome:** Resolution invalidated; re-evaluation scheduled.

### Security and Recovery Scenarios (Z–AH)

#### Scenario Z: Path Traversal Attempt
- **Initial State:** Member declares `target_relative_path: "../../Windows/System32/evil.dll"`.
- **Execution:** Path normalization detects `..` escape outside staging root.
- **Expected Outcome:** Immediate quarantine; fatal security alert `ERR_PVA_ZIP_SLIP`.

#### Scenario AA: Malformed Nested Content
- **Initial State:** Manifest JSON declares 500 levels of nested dependency objects.
- **Execution:** Parser resource limit detector measures recursion depth.
- **Expected Outcome:** Parse aborted at depth 16 with `ERR_PVA_RES_EXCEEDED`.

#### Scenario AB: Validation Service Unavailable
- **Initial State:** Out-of-process validator worker crashes on startup.
- **Execution:** Supervisor detects abnormal worker exit.
- **Expected Outcome:** Marked `ERR_PVA_VAL_TIMEOUT`; readiness blocked; safe retry initiated.

#### Scenario AC: Authorization Revoked After Package Validation
- **Initial State:** Package validated; user subsequently revokes project authorization in settings.
- **Execution:** Stage M pre-application check re-validates authorization token.
- **Expected Outcome:** Handoff revoked; package marked `BLOCKED`.

#### Scenario AD: Cancellation During Dependency Resolution
- **Initial State:** User clicks "Cancel" mid-way through DAG evaluation.
- **Execution:** Cancellation token tripped; staging workspace cleared.
- **Expected Outcome:** Graceful abort with `ERR_PVA_CANCELLED`; zero partial artifacts preserved.

#### Scenario AE: Concurrent Artifact Revision Change
- **Initial State:** Worker B modifies asset file while Assembler A computes digest.
- **Execution:** File lock check detects concurrent write.
- **Expected Outcome:** Assembly aborted with `ERR_PVA_CONCURRENCY`; re-run required.

#### Scenario AF: Package Contains Unapproved Executable Action
- **Initial State:** Package manifest attempts to register post-install script hook `Setup.bat`.
- **Execution:** Security policy evaluator inspects registered actions.
- **Expected Outcome:** Immediate rejection with `ERR_PVA_EXEC_PAYLOAD`.

#### Scenario AG: Optional Warning Improperly Treated as Waiver
- **Initial State:** Automated agent sets `ignore_errors: true` on critical SHA-256 mismatch.
- **Execution:** Waiver guardrails verify check criticality.
- **Expected Outcome:** Waiver rejected with `ERR_PVA_WAIVER_DENIED`; package blocked.

#### Scenario AH: Package Passes Static Validation, Lacks Runtime Evidence
- **Initial State:** Package completely valid statically; no in-game launch test has been performed.
- **Execution:** Readiness evaluator sets runtime status.
- **Expected Outcome:** Marked `VALIDATED` with explicit warning `ERR_PVA_RUNTIME_UNPROV`; zero claim of verified gameplay operation.
