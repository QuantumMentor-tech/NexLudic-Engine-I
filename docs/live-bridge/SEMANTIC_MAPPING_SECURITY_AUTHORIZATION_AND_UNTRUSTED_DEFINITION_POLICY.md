## 1. Purpose and Scope

This policy governs the security boundaries, authorization controls, execution sandboxing, and trust classifications for **Semantic Mapping Definitions**, with particular focus on untrusted community-authored mappings and AI-agent generated mapping proposals.

Because semantic mappings define how data is parsed, calculated, and projected into live game runtimes, malicious or defective mapping definitions could trigger memory exhaustion, infinite loops, integer overflows, or game crashes. This policy ensures total isolation and defensive resilience.

---

## 2. Trust Classification and Approval Tiers

Every Semantic Mapping Definition belongs to one of four Trust Tiers:

| Trust Tier | Source / Provenance | Signature Requirement | Verification Rigor | Execution Rights |
| :---: | :--- | :--- | :--- | :--- |
| **TIER 0: BUILTIN** | Official NexLudic core engine distribution. | Signed by NexLudic Engine Release Key. | Full static & dynamic test suite verified. | Full execution rights; zero sandbox restriction. |
| **TIER 1: VERIFIED** | Verified game publishers or accredited integration partners. | Signed by Partner X.509 Certificate in trust store. | Passed automated 14-layer pipeline + static analysis. | Full execution rights; standard AST limits. |
| **TIER 2: COMMUNITY**| User-created or community-shared mapping definitions. | Optional self-signed certificate. | Passed 14-layer pipeline + strict AST quotas. | Sandboxed execution; strict resource budgets; user confirmation required. |
| **TIER 3: AI-PROPOSED**| Generated by local AI Orchestration Agent (Phase 7). | Unsigned `DRAFT_AI_PROPOSED` status. | Must undergo offline test suite and human approval. | **Execution Forbidden in Active Sessions** until promoted to Tier 2 by human user. |

---

## 3. Sandboxed AST Derivation Execution Constraints

To eliminate arbitrary code execution, buffer overflow, and denial-of-service vulnerabilities, the Derivation Expression Evaluator operates under strict hardcoded limits:

1. **Zero External I/O:** The AST evaluator has no access to the filesystem, network sockets, OS system calls, or environment variables.
2. **Execution Time Budget:** Any mapping calculation that does not terminate within **$50 \ \mu\text{s}$** per entity is aborted immediately (`ERR_SEM_EVALUATION_TIMEOUT`).
3. **Maximum AST Depth:** Maximum tree depth $= 8$ levels.
4. **Maximum Operator Count:** Maximum operator nodes per derived property $= 32$.
5. **Memory Allocation:** Zero dynamic heap allocations inside the per-message evaluation path.

## 5. Privacy, PII Redaction and Data Minimization

1. **PII Stripping:** Semantic mappings must not pass unencrypted Personally Identifiable Information (IP addresses, hardware MAC addresses, user email addresses, local Windows account names).
2. **Telemetry Redaction:** Host-game diagnostic traces containing local memory addresses or process handles are automatically stripped before crossing the bridge boundary.
3. **Data Minimization:** Only properties explicitly declared in the Target Domain Concept Descriptor are materialized in the outbound payload.
